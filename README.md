# King County House Sales Dashboard

Interactive Tableau dashboard analyzing residential home sales in King County, WA — price trends, price distribution, bedroom/bathroom counts, and view/condition ratings across zip codes.

## Live Dashboard
[View it here](https://public.tableau.com/app/profile/godknows.unula3407/viz/KingCountyHouseSalesDashboard_17907947918010/Dashboard1?publish=yes)

## What it shows
- Daily average sale price trend
- Price distribution by bin
- Price by zip code (map)
- View and condition ratings vs. average price
- Bedroom and bathroom count distributions
- Filters: year/month, year built, sqft living, sqft lot, price range

## Tools used
Tableau Public, calculated fields, filled maps, interactive filters
